# Lidl Finland (lidl.fi)

Stores: Lidl stores in Finland.

| Destination | Supported | Notes |
| --- | --- | --- |
| Price check | Yes | A signed-in user can browse product prices and select a store to see its store-specific offers. |
| Shopping list | No | Not available on the website. |
| Cart | No | Lidl Finland does not offer online grocery orders on its website. |
| Time slot, order, payment | Out of scope | Not available, and outside this skill in any case. |

## Site notes

- If the user asks for a Lidl shopping list or cart, explain that the website does not offer one. Offer a price check at the store they choose, with the result formatted for shopping in the store.
- Selecting the store the user named, so the site shows its offers, is part of the price check. Do not change other account settings.
- Keep regular prices and offers apart. Record each offer's validity dates and any condition shown, such as needing the store's app or loyalty program.
- If an item is not listed online, mark it unpriced. Do not conclude the store does not sell it.
- The account also shows the user's electronic receipts. They are personal purchase history. Open them only when the user explicitly asks, for example to compare past prices; use only what the task needs, and do not copy receipt contents into a repository or saved profile.

## If the site differs

These notes reflect the site as tested in November 2026. If Lidl adds lists or online ordering, follow what you see, tell the user about the difference, and do not use a new feature as a destination until the user asks for it.
